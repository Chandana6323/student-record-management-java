# Student Record Management System (Java)

This is a simple Java console-based application developed to practice core Java and Object-Oriented Programming concepts.

## Features
- Add student records
- View student records
- Manage data using ArrayList
- Console-based execution

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- VS Code

## Purpose
This project was created to strengthen Java fundamentals and understand basic data handling using collections.

## How to Run
1. Open the project folder in VS Code
2. Run `Main.java`
3. View output in the terminal
